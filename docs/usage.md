# 使い方ガイド

## 推奨フロー

1. ダッシュボードでプロジェクトを作成
2. **WBS** タブでタスクを階層登録（所要日数・進捗）
3. **ネットワーク図** で**依存関係を設定**し、クリティカルパスを確認
4. **ガント** でスケジュールを俯瞰し、計画が固まったら**ベースラインを保存**
5. 実行中は WBS で**進捗を入力**
6. ダッシュボードで **SPI を確認**し、遅延の兆候を早期に把握
7. **リスク / 関係者** タブで登録簿を随時更新

## 依存関係エディタ（ネットワーク図）

**ネットワーク図** タブでタスク間の依存関係を直接編集できます。

- 先行タスク・後続タスクを選んで依存を追加
- 依存タイプを選択: **FS**（終了→開始）/ **SS**（開始→開始）/ **FF**（終了→終了） / **SF**（開始→終了）
- **ラグ**（待ち日数。負値はリード）を日数で指定
- エッジにはタイプとラグがラベル表示され、凡例で読み方を確認できます

依存を変更するとクリティカルパスと開始/終了日が自動で再計算されます。

## スケジュールベースライン（ガント）

ベースラインは「承認した時点の計画のスナップショット」です。保存しておくと、その後の計画変更や遅れを当初計画との差として測れます。計画が承認されたタイミングで **ガント** タブからベースラインを保存します。

- **灰色のバー** = ベースライン保存時（承認時）の計画
- 色付きのバーが現在の計画。バー内の濃い塗りつぶしは**進捗率**
- **赤い縦の点線** = 今日の位置
- 各タスクに終了日の差異が **±n日** で表示されます（**+n日 = 計画より遅延（赤）**、−n日 = 前倒し（緑）、±0 = 計画どおり）

ガント画面では「ベースラインと差異バッジの見方」を開くとこの凡例をいつでも確認できます。チャートの直上にもバー・進捗・今日線の凡例が表示されます。

ベースラインは複数保存でき、不要になったものは削除できます。

### ベースライン API

```
POST   /api/projects/:id/baselines   # 現在の計画をベースラインとして保存
GET    /api/projects/:id/baselines   # ベースライン一覧
DELETE /api/baselines/:id            # ベースライン削除
```

## 簡易EVM と SPI（ダッシュボード）

ベースラインを保存すると、日数ベースの簡易 EVM 指標を算出します。

- **PV**（計画価値）: 基準日までに完了している計画の日数
- **EV**（出来高）: 進捗率を加味した実際の達成日数
- **SPI** = EV ÷ PV（スケジュール効率）

ダッシュボードの各プロジェクトカードに SPI バッジが表示されます。

| SPI | 表示 | 意味 |
|-----|------|------|
| 1.0 以上 | 緑 | 順調（計画どおり以上） |
| 0.85 以上 1.0 未満 | 黄 | 注意（やや遅延） |
| 0.85 未満 | 赤 | 遅延（対策が必要） |

## 登録簿（リスク / 関係者）

- **リスク登録簿**: 確率・影響・状態を select で編集。確率×影響の**リスクスコア（1〜9）**がバッジで表示され、高スコアほど優先対応
- **ステークホルダー登録簿**: 権力・関心の高低から**権力・関心グリッド**の区分（注意深く管理 / 満足状態を維持 / 常に情報提供 / 監視）を自動表示

## JSONエクスポート / インポート

プロジェクト一式（タスク・依存・マイルストーン・リスク・関係者など）を JSON でバックアップ・移行できます。

1. **エクスポート**: 画面のエクスポート操作、または `GET /api/projects/:id/export` で JSON をダウンロード
2. **インポート**: 画面のインポート操作で JSON を選択（または `POST /api/projects/import` に送信）すると、新しいプロジェクトとして取り込まれます

```bash
# CLI での例
curl -s http://localhost:3000/api/projects/<id>/export > project.json
curl -s -X POST http://localhost:3000/api/projects/import \
  -H "Content-Type: application/json" -d @project.json
```

## AIアシスト（プロンプト方式）

MCP 非対応の ChatGPT 等向け:

1. プロジェクト画面の **AIアシスト** タブを開く
2. 目的（WBSドラフト / タスク分解 / リスク / 依存）を選択
3. **プロンプトをコピー** して AI に貼り付け
4. 返ってきた JSON を貼り付けて **取り込む**

取り込み時の支援機能:

- ` ```json ` などのコードフェンスは**自動で除去**されるため、AI の回答をそのまま貼り付け可能
- 取り込み前に**プレビュー**で内容を確認してから反映
- JSON は Zod で検証され、不正な場合は**項目別のエラーメッセージ**が表示されます
